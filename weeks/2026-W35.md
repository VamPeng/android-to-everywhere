## 交付物 1：Android UI 卡顿引导实验

学习入口：[[../learning/android-performance/01-ui-jank-guided-lab|UI 卡顿 Trace 引导实验]]

- [ ] 阅读实验中的“最小概念”和 Trace 查看顺序。
- [ ] 新建或选择一个可公开的 Android 实验项目。
- [ ] 实现 `Sleep 80 ms` 和 `CPU Busy 80 ms` 两个受控故障。
- [ ] 为两个故障加入自定义 Trace 区间。
- [ ] 分别录制两份 Android Studio System Trace。
- [ ] 找到对应 Janky Frame 和 Main Thread 区间。
- [ ] 填写两份观察表，解释两种故障的 CPU 行为差异。
- [ ] 把 CPU 工作移出主线程并再次录制。
- [ ] 经 AI 核对后，使用 [[../templates/case-study|案例模板]] 保存第一份引导案例。

完成标准：

```text
不仅能制造卡顿
+ 能找到异常帧
+ 能判断主要瓶颈线程
+ 能关联自定义 Trace 与代码
+ 能区分墙上耗时和 CPU 时间
+ 有修复前后证据
```

本周不要求直接完成未知根因的独立案例。通过本实验后，下一周再进入半开放卡顿问题。
