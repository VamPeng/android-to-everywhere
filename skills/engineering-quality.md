# 工程质量

## 能力范围

- 单元测试、集成测试、UI 测试与性能基准。
- Lint、静态检查、依赖与安全扫描。
- 自动构建、签名、产物、版本和发布。
- 日志、Crash、ANR、接口和业务指标。
- 灰度、回滚、变更记录与事故复盘。
- Code Review、ADR、技术债务与质量门禁。

## 首批实战

- [ ] 为 Flutter 或 RN 业务状态补单元测试。
- [ ] 为 Android 性能案例建立可重复基准。
- [ ] 为一个项目配置基础 CI。
- [ ] 生成可追溯构建产物。
- [ ] 建立脱敏日志和错误码规范。
- [ ] 完成一次失败构建或故障复盘。

## 判断标准

工具安装不等于工程能力。只有当流程能自动发现问题、阻止回归或降低发布风险时，才算形成质量能力。
