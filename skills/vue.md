# Vue 管理后台

## 技术主线

- JavaScript / TypeScript 基础。
- Vue 3、组件、Composition API 与响应式。
- Vite、Vue Router、Pinia。
- Axios/Fetch 请求封装、错误和鉴权处理。
- 常用组件库、表格、分页、表单、上传和弹窗。
- RBAC、动态菜单、动态路由和按钮权限。
- ECharts 数据看板。
- Lint、测试、构建和部署。

## 验收模块

- [ ] 管理员登录与 Token 刷新。
- [ ] 用户、角色与权限。
- [ ] 动态菜单与路由。
- [ ] 列表、筛选、分页和复杂表单。
- [ ] 图片/文件上传。
- [ ] 日志查询和数据图表。
- [ ] 与 Java 后端完成联调、构建和部署。

## 目标边界

能独立完成常见企业管理后台，不要求近期达到大型前端基础设施或复杂可视化专家水平。
