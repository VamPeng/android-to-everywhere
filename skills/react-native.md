# React Native

## 目标边界

能独立设计、开发、调试和发布常规 React Native 项目；能区分 JavaScript、框架层与原生平台问题。

## 必备能力

- TypeScript 类型系统、异步、模块与工程配置。
- React 组件、Hooks、状态、渲染与副作用。
- 导航、状态管理、网络、本地存储和缓存。
- 列表、表单、媒体、权限和异常处理。
- Android/iOS 构建、签名与发布。
- 原生模块、原生 View 与平台桥接基础。
- JS、渲染和 Native 三层日志与性能排查。
- 单元、组件和关键流程测试。

## 实战顺序

- [ ] 登录与表单状态。
- [ ] 列表、分页、详情和缓存。
- [ ] 图片选择与上传。
- [ ] SSE 流式消息。
- [ ] Android 原生模块。
- [ ] 测试、构建和发布。

## 中级验收

能脱离整页生成完成常规模块；能解释 Hook、状态和原生调用链；能处理常见构建、网络、渲染和桥接问题；能局部重写 AI 生成代码。
