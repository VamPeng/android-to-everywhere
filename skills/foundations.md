# 计算机与语言基础

## 学习原则

每个基础主题必须绑定一个实际问题，避免只背概念。

| 主题 | 实战载体 |
|---|---|
| Kotlin / Java 类型、泛型、反射 | 设计可扩展 SDK API，验证类型安全与兼容 |
| JVM、GC、类加载、字节码 | 分析启动、内存和反射问题 |
| 并发、JMM、锁、线程池 | 制造竞态、死锁、线程膨胀并修复 |
| 协程与异步模型 | 取消、超时、错误传播和并发安全 |
| TCP、TLS、HTTP、DNS | 弱网、连接复用、超时和重试实验 |
| 操作系统进程、线程、I/O | ANR、阻塞、文件与内存问题 |
| SQLite、事务、索引、锁 | 查询慢、迁移失败、并发写入问题 |
| 数据结构与算法 | 真实缓存、队列、索引和调度场景 |

## 完成标准

- 能在代码中复现对应问题。
- 能说明为什么发生，而不只会调用修复 API。
- 能将结论迁移到 Android、Flutter、RN 或 Java 后端。
