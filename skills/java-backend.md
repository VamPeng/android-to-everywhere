# Java 后端

## 目标边界

掌握正常的 Java 服务端开发能力：能独立设计、开发、测试、部署和排查常规管理系统后端，而不只是依赖 AI 生成 CRUD。

## 必备能力

- Java 语言、集合、泛型、异常、反射、注解和 I/O。
- JVM、并发、线程池与基础性能分析。
- Maven 或 Gradle 构建与依赖管理。
- Spring Boot、MVC、参数校验、统一异常和配置。
- Spring Security、JWT、RBAC。
- MySQL/PostgreSQL、索引、事务和迁移。
- MyBatis/JPA 选择与数据访问。
- Redis、缓存一致性和过期策略基础。
- 文件上传、对象存储、SSE/WebSocket。
- JUnit、Mock、接口与集成测试。
- 日志、监控、Docker 和部署。

## 验收模块

- [ ] 登录、刷新 Token 和 RBAC。
- [ ] 用户与内容 CRUD，包含校验和事务。
- [ ] 分页、筛选和索引验证。
- [ ] 文件上传与对象存储。
- [ ] SSE AI 流式接口。
- [ ] 测试、容器化与部署。
- [ ] 主动制造并定位一次事务、并发或性能问题。
