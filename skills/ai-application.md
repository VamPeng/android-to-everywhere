# AI 应用工程与 AI 协作

## AI 产品能力

- 模型 API、流式响应与取消。
- 多轮上下文、结构化输出和状态管理。
- Tool Calling / Agent 基础。
- RAG 基础、数据边界与检索质量。
- 超时、重试、降级、限流和成本控制。
- 结果评估、错误分类、日志和可观测性。
- 隐私、安全和敏感数据处理。

## AI 辅助研发能力

- 需求拆分与约束表达。
- 先设计数据流和接口，再让 AI 实现局部。
- 审查依赖、异常、并发、生命周期和安全边界。
- 使用测试、日志、Trace 和故障注入验证结果。
- 识别生成代码债务，能局部重写而非整段重生成。

## 首批证据

- [ ] Flutter 或 RN 的 SSE AI 会话。
- [ ] Java 后端的流式代理接口。
- [ ] 一个 Tool Calling 功能。
- [ ] 一个可重复的输出评估样例。
- [ ] 一份 AI 生成代码审查与修复案例。
