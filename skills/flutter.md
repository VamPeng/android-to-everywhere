# Flutter

## 目标边界

能独立设计、开发、调试和发布常规 Flutter 项目；不要求近期达到框架源码或渲染引擎专家水平。

## 必备能力

- Dart：类型、空安全、泛型、异步、Stream、异常。
- Widget、布局、生命周期与渲染更新。
- 状态管理、路由、依赖注入与模块边界。
- 网络、本地存储、序列化、缓存与错误处理。
- 图片、文件、权限和常用平台能力。
- Android/iOS 构建、签名、发布与环境配置。
- Platform Channel、插件使用与基础原生桥接。
- 基础性能、日志、测试和问题定位。

## 实战顺序

- [ ] 登录与表单状态。
- [ ] 列表、分页、详情和缓存。
- [ ] 图片选择与上传。
- [ ] SSE 流式消息。
- [ ] 平台能力桥接。
- [ ] 测试、构建和发布。

## 中级验收

能脱离整页生成完成常规模块；能解释状态与生命周期；能处理常见构建、网络、布局和异步问题；能审查并局部重写 AI 生成代码。
