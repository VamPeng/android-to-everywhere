# Android 深度

## 当前基础

- 约 7 年 Android 应用层开发。
- 普通业务实现很强，复杂模块、架构设计和独立方案熟练。
- 有 Jetpack、Compose、Clean Architecture、模块化和公共组件经验。
- 线上问题主要依赖日志，缺少完整证据链与大规模稳定性治理。

## 深入主轴

1. 系统机制：进程、线程、Looper、Binder、组件启动、渲染、ART。
2. 性能：启动、卡顿、ANR、内存、I/O、网络、电量与包体积。
3. 疑难排障：复现、现场证据、根因调用链、修复、回归。
4. 编译构建：Gradle、AGP、KSP、D8/R8、DEX、缓存和依赖治理。
5. 工程质量：测试、CI/CD、监控、灰度、发布与稳定性指标。
6. 架构：模块边界、状态与数据流、SDK 设计、重构和技术决策。

## 首批实战案例

- [ ] 页面滑动卡顿：Trace → 根因 → 数据对比。
- [ ] 冷启动：启动链路 → 主线程任务 → 基准验证。
- [ ] 主线程/锁竞争 ANR。
- [ ] 内存泄漏与 OOM。
- [ ] 网络弱网、重试与幂等。
- [ ] Gradle 构建耗时与缓存。
- [ ] 一个 CI/CD 与自动化测试闭环。

## 掌握标准

不以“读过源码”为完成，而以能够从现象追到系统机制、拿出证据并验证修复为完成。
