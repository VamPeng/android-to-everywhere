# Android to Everywhere

> 以 Android 为根，建立跨端、原生多平台、前端与 Java 后端的独立开发能力。

这是个人职业能力规划与实战证据总仓库。GitHub 保存唯一真实内容，Obsidian 直接打开本地仓库作为阅读、编辑和聚合面板。

## 能力路线

| 优先级 | 方向 | 目标 |
|---|---|---|
| P0 | Android 原生深度 | 持续深入系统机制、性能、疑难排障、构建与工程质量 |
| P1 | Flutter + React Native | 同等优先级；达到可独立完成常规项目的中级水平 |
| P2 | iOS + HarmonyOS 原生 | 掌握语言、UI 与常用系统 API，能独立完成基础业务 |
| P3 | Vue 管理后台 + Java 后端 | 能独立完成常规企业业务的开发、调试与维护 |
| 横切 | AI 应用与 AI 协作 | 能解释、修改、验证和排查 AI 参与生成的代码 |

## 新会话继续工作

新开 AI 会话时，只需提供仓库地址并要求先读取 `AI_HANDOFF.md`：

```text
接管我的职业规划仓库：
https://github.com/VamPeng/android-to-everywhere
先读取 main 分支的 AI_HANDOFF.md，并严格按其中协议工作。
本次任务：检查当前 Week 进度并确定下一步。
```

`CURRENT_STATUS.md` 保存当前季度、当前 Week、进度、阻塞和唯一下一步。每次会话结束都应更新它。

## 使用方式

```text
GitHub main 分支：唯一权威数据
        ↑↓ Git
本地仓库：标准 Markdown 文件
        =
Obsidian Vault：导航、查询与复盘面板
```

1. 克隆仓库。
2. 在 Obsidian 中选择 **Open folder as vault**，打开仓库根目录。
3. 每周只创建少量、可验收的交付物。
4. 代码放在各技术项目仓库，本仓库保存计划、案例、证据链接与复盘。
5. 每周提交一次进度，每季度重估优先级。

## 掌握标准

一项能力只有同时满足以下条件，才能从“接触过”升级为“掌握”：

```text
能运行 → 能解释 → 能修改 → 能排错 → 能独立重建核心部分
```

AI 生成并成功运行，只算完成第一次接触，不算掌握。
