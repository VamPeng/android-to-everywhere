# 05：媒体、文件、权限与平台隐私

## 本章目标

能在 Android/iOS 差异下安全选择、读取、预览和上传媒体文件，并处理 URI、权限、平台隐私、进度、取消和内存风险。

## 教学节点

1. Asset、网络图片与本地文件；
2. 图片解码、尺寸、缓存与内存风险；
3. Path、URI、字节流、应用目录、临时目录和外部文件句柄的区别；
4. 相册、相机、文件选择与返回句柄的生命周期；
5. Android/iOS 权限声明、运行时授权、永久拒绝和设置页恢复；
6. Android 分区存储、Content URI 与 iOS Sandbox、有限照片权限；
7. 平台隐私声明、用途说明、最小权限和敏感日志边界；
8. MIME Type、文件签名、大小校验、EXIF/方向和元数据隐私；
9. Multipart/流式上传、上传进度、取消、有限重试和幂等；
10. 压缩、缩略图、大文件分块读取和临时文件清理；
11. 页面/App 生命周期、相机/选择器返回和后台上传限制；
12. 平台 Capability/Policy 分支与可测试封装。

## L0 概念门禁

- 能说明 Path、Content URI、文件字节和图片解码结果不是同一层对象；
- 能解释 Android/iOS 权限状态、有限授权、平台隐私声明与恢复路径；
- 能画出选择 → 校验 → 解码/压缩 → 上传 → 清理的资源生命周期。

## L1 引导实验

```text
请求权限
→ 选择图片
→ 显示本地预览
→ 校验类型、签名、大小和方向
→ 压缩并模拟流式上传进度
→ 取消或失败重试
→ 清理临时文件
```

## L2 半开放任务

- 拒绝权限后仍访问文件；
- 加载超大图片造成明显内存压力；
- 页面退出后上传进度仍更新 UI；
- Content URI 被当作普通路径使用；
- 有限照片权限、进程恢复或选择器返回后资源已失效；
- 扩展名与真实文件类型不一致。

## L3 综合实战

把图片选择与上传接入主项目：覆盖 Android/iOS 权限差异、预览、类型/大小校验、压缩、进度、取消、失败重试、页面退出和临时文件清理，并对平台能力进行可替换封装。

## 交付物与验收

- Android/iOS 权限差异表；
- 可运行图片选择上传流程；
- 取消、拒绝、有限授权、内存压力和失败重试证据；
- 至少一个权限/上传状态测试和一份脱敏日志；
- 能解释文件路径、字节数据、图片解码结果之间的区别。
