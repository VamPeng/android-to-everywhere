# 05：图片、文件与权限

## 本章目标

能在 Android/iOS 差异下安全选择、读取、预览和上传媒体文件，并处理权限、进度、取消和内存风险。

## 教学节点

1. Asset、网络图片与本地文件；
2. 图片解码、尺寸、缓存与内存风险；
3. 应用目录、临时目录和平台文件路径；
4. 相册、相机与文件选择；
5. Android/iOS 权限声明、运行时授权和拒绝分支；
6. Android 分区存储与 iOS 相册权限基础；
7. MIME Type、Multipart 上传和上传进度；
8. 压缩、取消、有限重试和临时文件清理。

## L1 引导实验

```text
请求权限
→ 选择图片
→ 显示本地预览
→ 校验类型和大小
→ 模拟上传进度
→ 取消或失败重试
```

## 故障任务

- 拒绝权限后仍访问文件；
- 加载超大图片造成明显内存压力；
- 页面退出后上传进度仍更新 UI。

## 交付物与验收

- Android/iOS 权限差异表；
- 可运行图片选择上传流程；
- 取消、拒绝和失败重试证据；
- 能解释文件路径、字节数据、图片解码结果之间的区别。
