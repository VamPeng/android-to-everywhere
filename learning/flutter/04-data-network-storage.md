# 04：网络、会话、存储、缓存与实时数据

## 本章目标

能构建可靠的数据与会话链路，区分远端、本地、缓存、实时数据与业务状态，并处理并发、取消、超时、错误和恢复。

## 教学节点

1. HTTP 客户端、请求参数、Header、响应与拦截器；
2. HTTPS 基础、敏感 Header 脱敏、请求日志与证书错误边界；
3. 登录会话、Access/Refresh Token、刷新并发、过期、退出与安全存储；
4. 超时、取消、有限重试、退避、幂等性与重复请求合并；
5. JSON 手工/代码生成序列化，以及 DTO、Domain Model、UI Model；
6. 键值存储、安全存储与结构化数据库的边界；
7. 数据库事务、Schema 版本和迁移失败处理；
8. 内存缓存、磁盘缓存、失效策略与单一事实来源；
9. Cache-First、Network-First、离线读取和数据新鲜度；
10. Offset/Cursor 分页、刷新、加载更多、去重与顺序一致性；
11. 网络、协议、鉴权、业务、数据和存储异常的分层映射；
12. 网络连接状态与服务真实可达性的区别；
13. Polling、SSE 与 WebSocket 的选择边界；
14. SSE 事件解析、取消、重连、退避、去重与页面/App 生命周期。

## L0 概念门禁

- 能画出 Service → Repository → Cache/Database → ViewModel 的数据流和单一事实来源；
- 能解释 Token 刷新、请求重试、幂等和并发去重之间的关系；
- 能为缓存、分页、实时连接和错误映射分别给出明确策略。

## L1 引导实验

完成带 Fake/真实数据源切换和模拟登录会话的分页列表：首次加载、空数据、加载更多、刷新、离线缓存、Token 过期和错误重试。

## L2 半开放任务

- 返回损坏 JSON；
- 同时触发刷新和加载更多；
- 页面退出后请求仍回写状态；
- 多个请求同时触发 Token 刷新；
- 数据库升级或缓存版本不一致；
- SSE 重连造成重复消息或重连风暴。

## L3 综合实战

登录会话 → 列表 → 详情 → 本地缓存 → 断网恢复 → SSE 流式消息 → 会话过期与退出清理。

## 交付物与验收

- 数据流与缓存策略说明；
- 会话、Token 刷新与敏感数据边界说明；
- 网络/鉴权/业务/数据/存储错误映射代码；
- 分页、Repository、缓存或迁移测试；
- 离线、超时、损坏数据、并发刷新和重试证据。
