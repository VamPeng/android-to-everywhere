# 04：网络、存储、序列化、缓存与错误处理

## 本章目标

能构建可靠的数据链路，区分远端、本地、缓存与业务状态，并处理取消、超时、错误和恢复。

## 教学节点

1. HTTP 客户端、请求参数、Header、响应与拦截器；
2. 超时、取消、有限重试和幂等性；
3. JSON 序列化与 DTO、Domain Model、UI Model；
4. 键值存储与结构化数据库的边界；
5. 内存缓存、磁盘缓存与失效策略；
6. Cache-First、Network-First 和单一事实来源；
7. 分页、刷新、加载更多与重复数据；
8. 网络异常、协议异常、业务异常和数据异常；
9. SSE 连接、事件解析、取消、重连与页面生命周期。

## L1 引导实验

完成带 Fake/真实数据源切换的分页列表：首次加载、空数据、加载更多、刷新、离线缓存和错误重试。

## 综合验收

列表 → 详情 → 本地缓存 → 断网恢复 → SSE 流式消息。

## 故障任务

- 返回损坏 JSON；
- 同时触发刷新和加载更多；
- 页面退出后请求仍回写状态；
- SSE 重连造成重复消息。

## 交付物与验收

- 数据流与缓存策略说明；
- 网络/业务/数据错误映射代码；
- 分页或 Repository 测试；
- 离线、超时、损坏数据和重试证据。
