# 实战案例

这里保存性能、疑难问题、构建、跨端和后端案例。每个案例必须包含问题现场、证据、根因、修复和验证。

## 命名

```text
YYYY-MM-DD-方向-问题.md
```

例如：

```text
2026-08-30-android-compose-list-jank.md
```

## 分类建议

- `android-performance`
- `android-debugging`
- `build`
- `cross-platform`
- `frontend`
- `backend`
- `ai`

创建案例时复制：[[templates/case-study|案例模板]]。
